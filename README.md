# POWERFLOW AI 2026 — Premium Seminar Website

A mobile-first, dark premium visual identity for the National Level Technical Seminar:
**AI-Based Optimal Power Flow for Sustainable Power Systems**

## Organising department
**Department of Electrical and Electronics Engineering (EEE), Kings College of Engineering (Autonomous)**. This department is explicitly highlighted in the hero section and organiser band.

## Included
- `index.html` — full website sections
- `style.css` — dark navy / teal / gold visual system, electrical grid illustration, animations, responsive mobile layouts
- `script.js` — mobile menu and scroll reveal
- `assets/` — college shield, supplied college branding banner, campus photo and three separately supplied speaker portraits

## Open locally
Extract the ZIP and open `index.html` in Chrome, Edge or Firefox. No package installation or build process is required. Google Fonts needs an internet connection; all supplied images are local assets.

## Deploy to Vercel
1. Extract this ZIP.
2. Create a GitHub repository and upload the contents of this folder (do not upload only the ZIP).
3. In Vercel, select **Add New → Project** and import the repository.
4. Choose **Other** as framework preset if prompted. Leave Build Command blank; use `.` as the output directory.
5. Deploy.

GitHub Pages and Netlify also support this static site.
